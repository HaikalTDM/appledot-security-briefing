What the change costsone row · zero code

Anon and fresh verified users are blocked from this write — so a homepage defacement needs an elevated account (or any future RLS gap, or a leaked admin session). The demo proves the visual; the RLS matrix proves the barrier. The risk is that the barrier is implicit, undocumented and untested — not that it is absent.

04 The verdict

The gap is not code quality. The gap is what the code never had to survive.

AI delivered
  • Working auth (OTP + password)
  • Correct RLS on every table probed
  • Server-side admin route gate
  • Modern Next.js on Vercel
  • Responsive, polished UI
  • Sentry error reporting wired
Nobody specified
  • Full Content-Security-Policy
  • Rate limits on login & OTP
  • Private bucket for KYC proofs
  • RLS tests in CI per table
  • Schema-hint suppression
  • Pagination caps on public data
The one sentence to remember: AI can write the lock, the door and the wall — but it does not ask “who is allowed to walk through, and what happens when someone forgets to install the door?” That question is the product. It cannot be autocompleted.
